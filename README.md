# Custom Virus Mod

Create and apply custom viruses with unique effects in Minecraft.

## Features

- Create and apply custom viruses with unique effects
- GUI for easy virus application

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Launch Minecraft with the mod installed.
2. Use the `/virus` command to open the Virus GUI.
3. Click the "Apply Virus" button to apply the custom virus effect.

## Configuration

The mod does not have a configuration file. Custom effects can be added by modifying the `VirusEffect` class.
